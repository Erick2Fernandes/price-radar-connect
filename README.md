# Preço Certo

Quero evoluir o projeto atual chamado PREÇORADAR.



ATENÇÃO:

NÃO recrie o projeto do zero.

Mantenha a identidade visual, componentes, funcionalidades e estrutura que já foram criados.

A partir deste prompt, transforme o projeto em uma plataforma completa com DOIS TIPOS DE USUÁRIO:



1. CLIENTE

2. MERCADO



O objetivo é transformar o PreçoRadar em uma plataforma que conecta consumidores e supermercados através de inteligência de preços.



==================================================

1. CONCEITO PRINCIPAL

==================================================



O PREÇORADAR possui dois lados:



👤 CLIENTE



O cliente utiliza a plataforma para:

- pesquisar produtos;

- comparar preços;

- descobrir onde determinado produto está mais barato;

- verificar disponibilidade;

- comparar vários mercados;

- montar uma lista de compras;

- descobrir em qual mercado sua lista fica mais barata;

- encontrar mercados próximos;

- acompanhar variações de preço;

- receber oportunidades de economia.



🏪 MERCADO



O mercado utiliza a plataforma para:

- cadastrar seu catálogo;

- importar produtos e preços;

- informar disponibilidade;

- acompanhar concorrentes;

- comparar seus preços com o mercado;

- acompanhar histórico;

- receber alertas;

- descobrir oportunidades;

- analisar margem;

- criar cesta estratégica;

- receber recomendações;

- encontrar fornecedores e oportunidades na Expoagro.



O diferencial do PreçoRadar é:



CLIENTE:

"ONDE É MAIS BARATO COMPRAR?"



MERCADO:

"COMO ESTOU POSICIONADO NO MERCADO?"



O sistema conecta essas duas necessidades.
